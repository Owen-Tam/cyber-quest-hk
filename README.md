# Cyber Quest 

 Cyber Quest is a game built with the Godot Engine and GDScript that educates students on digital safety principles, deepfake and AI security risks. 

 ## :magic_wand: Technologies
* GDSCript
* Godot Engine

## :magic_wand: Features 
* 5 levels filled with educational cybersecurity content targetted towards primary school students
* Automatically validated multiple-choice challenges within each level
* Unique boss challenges on each level to interactively test students' knowledge e.g. password validator, rapid Q&A, etc.
* Engaging storyline that brings the player on an adventure across "Cyberia" to defeat the "Malware Master"

## :brain: Process
The game was developed in collaboration with Diocesan Boys' School Primary Division to enhance the cybersecurity awareness of students. Beginning in Early 2024, the pixel art design and educational content for the game was first developed, after which the game was built in the Godot Engine. I chose to use the Godot Engine due to its growing open source community, its support for web-based games, and relatively light-weight features. A tilemap system was used to produce the isometric platform for the game and game mechanics made use of the tilemap to manage the player's movement throughout the levels. 

## :vertical_traffic_light: Running the project
1. Clone the repository
2. Load project using Godot v4.2.2 
3. Run project (Press F5)
